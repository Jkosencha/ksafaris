# Guest reviews

Add one `.yaml` file per review here and it will appear on `/reviews`. Only publish real reviews,
with the guest's permission. Example (`jane-d-2025.yaml`):

```yaml
author: Jane D.
country: United Kingdom
quote: >-
  Paste the guest's words here exactly as written.
rating: 5
source: Tripadvisor
sourceUrl: https://www.tripadvisor.com/...
date: 2025-08-14
tour: 13-days-kenya-tanzania-expedition # optional, must match a tour file name
```
